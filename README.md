# 💰 Expense Tracker

A full-stack web application that helps users manage their personal finances by tracking income and expenses in one place. Users can add, view, edit, and delete transactions, categorize their financial activities, and keep track of their spending.

## ✨ Features

- 🔐 **User Authentication** — Secure registration and login using JWT and bcrypt.
- 💸 **Income & Expense Management** — Add and manage financial transactions.
- 🗂️ **Transaction Categories** — Organize transactions by category.
- ✏️ **CRUD Operations** — Create, read, update, and delete transactions.
- 📊 **Financial Overview** — Track income and expenses.
- 🌙 **Dark/Light Mode** — Switch between themes for a better user experience.
- 📱 **Responsive UI** — Designed for different screen sizes.
- 🔒 **User-Specific Data** — Manage transactions associated with the authenticated user.

## 🛠️ Tech Stack

**Frontend:** React.js, Tailwind CSS, React Router, Context API

**Backend:** Node.js, Express.js, REST APIs

**Database:** MongoDB, Mongoose

**Authentication & Security:** JWT, bcrypt, authentication middleware

**Tools:** Git, GitHub, Postman, npm

## 🎯 Project Goal

The goal of this project is to build a practical personal finance management application while strengthening full-stack development skills, REST API integration, database management, authentication, and state management.
